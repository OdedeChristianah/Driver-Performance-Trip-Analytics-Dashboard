# Driver-Performance-Trip-Analytics-Dashboard
I developed an interactive Power BI dashboard to analyze driver performance, trip activity, revenue efficiency and on-time delivery across a three-year period. The dashboard enables users to explore performance by driver, home terminal and years of experience while identifying high- and low-performing drivers.
